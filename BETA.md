# Closed Beta — v0.3.0-beta

This is a beta release of the DivergentDecisions MCP server. Here is what that means in plain terms.

## What you can do

- Use it for personal, non-commercial idea museum work
- File bug reports and feedback — this is how the tool improves
- Share the GitHub repo URL with others who might want to test it

## What you should know

- Behaviour may change between releases without notice
- Not all features described in the architecture are fully operational yet — see [docs/known-limitations.md](docs/known-limitations.md) for an honest list
- This is not a finished product and is not intended for production use
- **Windows only** — the author does not own a Mac. The server may work on Mac in principle but this has not been tested. If you get it running on Mac, please share what you found in [Discussions](../../discussions).

## What you cannot do

- Redistribute the binary
- Use it in a commercial context
- Modify and redistribute

## Questions or problems?

File an issue. That is the most useful thing you can do during a beta.
