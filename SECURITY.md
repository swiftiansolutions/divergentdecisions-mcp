# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the DivergentDecisions MCP server, please report it privately rather than opening a public issue.

**Contact:** security@swiftiansolutions.com

Please include:

- A description of the vulnerability and what it could allow
- Steps to reproduce it
- The version you are running (e.g. v0.3.0-beta)
- Your OS and Claude Desktop version

**Response time:** This is a solo-maintained closed beta. Reports will be acknowledged within 14 days. Confirmed vulnerabilities will be addressed before the next release where possible.

Public disclosure is welcome after a fix is available, or after 90 days from the date of report, whichever comes first.
